# Render the module slides

## Preview one deck

From the repository root, run:

```bash
quarto preview slides/module-introduction.qmd
```

or:

```bash
quarto preview slides/module-conclusion.qmd
```

## Render both decks

```bash
quarto render slides
```

The rendered presentations are written to `docs/slides/`.

## Record

1. Open a rendered presentation in a 16:9 browser window.
2. Record the presentation window.
3. Advance the slides manually.
4. Export or upload the recording with captions.
